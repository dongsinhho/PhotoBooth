## Printer software path

- StoreConfig v2 supports an operator-managed printer block. Canonical default remains `printer.enabled=false`.
- Wails Windows Preview constructs an independent local + durable printer coordinator only for real-camera sessions when explicitly enabled.
- Root CLI and demo sessions remain local-only. Local-output retry/recovery cannot resubmit a printer job.
- UI reports local-save and spooler-acceptance outcomes separately. A queued Windows job is not represented as physical paper.
- Windows GDI per-job DEVMODE supports the exact driver media form name (`dmFormName`), with a 31 UTF-16 code-unit limit, DocumentPropertiesW validation, and preservation of vendor-private DEVMODE bytes.
- Durable printer intent/attempt state and Windows kernel-held print locks protect crash recovery. Reconciliation is conservative and does not query/resubmit jobs as a way to claim paper output.

## Windows release authenticity

- Unsigned Preview package build/install/start/rollback require explicit `-AllowUnsignedPreview`. Unsigned manifests remain on `internal-alpha`; installer rejects them by default.
- Signed candidates use an Authenticode-signed `release-manifest.ps1` envelope containing base64 JSON. The installer validates envelope signature and publisher thumbprint before parsing trusted metadata.
- Builder signs staged copies of EXE and SMB helper, plus the manifest envelope; source/build-tree artifacts are not modified.
- Installer validates publisher, Authenticode signatures, file sizes and SHA-256; it fails closed for tampering, empty/untrusted publisher allowlists, mixed manifests and same-version signature/publisher/helper collisions.
- Production publisher allowlist remains empty. No genuine publisher certificate, TSA, external thumbprint confirmation, real signed production candidate, public distribution, or automatic update transport is complete.
- Signing smoke used a disposable TEST-ONLY self-signed Code Signing certificate, then removed it from CurrentUser My/Root/TrustedPublisher. Original build-tree EXE/helper remain NotSigned.
