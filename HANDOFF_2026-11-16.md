## Stage 2 SMB default-off policy and helper — 2026-11-16

This supersedes the older next-step wording above that left the deployed SMB policy undecided.

**Accepted product decision:** Windows booth deployments should have SMB Server (LanmanServer) and workstation administrative shares disabled by default. SMB remote administration is a separate explicit operator-maintenance action, never a guest-photo delivery path.

**Opt-in contract:** invoke a package-owned PowerShell helper through Windows UAC. Enable is limited to one physical adapter already classified Private by Windows and literal RFC1918 remote IPv4 source addresses explicitly supplied by the operator. It opens inbound TCP 445 only on the selected local address and Private profile, while keeping the PhotoBooth TCP 445 Block rule active on Public and Domain profiles. Legacy NetBIOS TCP 137/139 and UDP 137/138 stay blocked. It does not enable SMB1/guest access, change ACLs, create guest shares, change a Public network to Private, or configure router port forwarding. Disable removes only the PhotoBooth Allow rule, installs PhotoBooth-owned inbound blocks, sets AutoShareWks=0, and stops/disables LanmanServer. Both state-changing actions abort on active sessions, running service dependents, custom SMB shares, or conflicting SMB rules rather than force changes.

**Prototype created:**
- docs/adr/0031-opt-in-windows-smb-administration.md records the accepted policy and remaining validation gates.
- tools/self-service/manage-smb-remote-admin.ps1 provides Status, Enable, and Disable.
- tools/self-service/README.md, docs/knowledge-base/SECURITY_PRIVACY.md, NETWORK_EXPOSURE_AUDIT.md, ROADMAP.md, and knowledge-base index now reference the policy/helper.

**Validation actually performed:** PowerShell AST parse passed. Extracted IPv4 validator accepted four valid RFC1918 examples and rejected public/out-of-range/wildcard/CIDR tokens. Read-only -Action Status ran successfully on ShinPc and correctly reported:
- LanmanServer Running / Automatic.
- AutoShareWks not explicitly configured.
- PhotoBooth-managed Allow/Block rules absent.
- ADMIN$, C$, IPC$ present.
- TCP445/139 listeners present on previously audited interfaces.

**No state-changing operation was run.** ShinPc remains unchanged and is not yet in the accepted default-off state. No UAC Enable/Disable, firewall, registry, service, share or account mutation was performed.

**Remaining gates before adoption:** validate Enable/Disable/rollback, AutoShareWks behavior, firewall rule filters and reboot persistence on a disposable Windows 11 Pro image; check allowlisted vs non-allowlisted reachability and NetBIOS blocks; verify local camera/capture/render/save regression with LanmanServer stopped; review dependencies and C$/INTERACTIVE share ACL semantics; integrate the helper into the operator UI/provisioning so new booth images actually begin in the default-off state. Until then, ADR policy is accepted but the helper is a prototype, and Stage 2 remains OPEN. No commit or push performed.
