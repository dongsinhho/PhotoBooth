# Optional Feedback Guide — Photobooth Self-Builders

**Status:** Optional feedback aid; not a project gate
**Target duration:** 15–25 minutes
**Purpose:** Use only if a prospective user voluntarily offers feedback. The core plan does not depend on conducting formal interviews.

## Principles

- Ask about real behavior, recent setup attempts, and concrete blockers.
- Do not imply PhotoBooth supports untested hardware/features.
- Ask permission before recording.
- Do not collect guest photos, credentials, or sensitive customer/payment data.
- Record exact quotes separately from interpretation.
- Successful install/capture attempts provide stronger evidence than polite interest.

## Optional questions

### About the build
1. Are you building your first booth or adding a new one?
2. Which camera, PC/OS, and printer do you plan to use?
3. Which equipment do you already own or intend to source used?
4. What parts of setup are you comfortable handling yourself?

### About software choice
5. What software or guide are you currently considering?
6. What matters before you commit: cost, setup difficulty, camera compatibility, print quality, support, cloud delivery, or something else?
7. What would make a free self-install app too risky to use?
8. Which hardware/software compatibility information do you need before downloading?

### About configuration
9. Which settings must be changeable without editing code: countdown, shot count, shot interval, print delay, frame/layout, output size, branding, or other settings?
10. Would a documented frame/theme package be enough, or what application-level capability is missing?

### About support and delivery
11. If you got stuck on camera/printer integration, what help would you look for and when would you pay for help?
12. Do you prefer local-only storage, LAN photo download, or optional cloud delivery?
13. How do you expect guests to receive photos? Is payment part of the first session?

### Optional test invitation
14. Would you voluntarily try a technical alpha when a supported hardware combination is available?
15. If you do, may we record the camera/OS/output details and whether capture-to-output succeeded, without collecting your guests' photos?
