### New harness behavior

`tools/ui-spike/wails-v2/ui-preview-kiosk-soak.ps1` now supports:
- `-PreflightOnly`: read-only host inventory and memory preflight; does not start the camera or PhotoBooth.
- `-RequireLowRamHost`: refuses a soak if visible physical RAM exceeds the configured ceiling, before camera/app startup.

- Host-wide system memory telemetry in each resource sample: available physical memory MB/percent, committed MB, commit limit/percent, `PagesInputPersec`, and `PageReadsPersec`.

Example for an actual target device:
```powershell
.\ui-preview-kiosk-soak.ps1 -PreflightOnly
.\ui-preview-kiosk-soak.ps1 -DurationMinutes 10 -RequireLowRamHost
```
